Tutorial operacional

Como configurar o Google Drive como storage padrão do licenciado

Este guia mostra o fluxo completo para conectar um Google Drive compartilhado ao Gestão Segura, permitindo que os novos anexos sejam armazenados diretamente no repositório da organização.

Destino Google Drive compartilhado
Pré-requisito Google Workspace + permissões administrativas
Resultado Storage padrão do licenciado configurado

Aviso importante

Responsabilidade da organização

Se a associação optar por usar o próprio storage via Google Drive, a responsabilidade pela manutenção, organização, retenção e integridade dos arquivos passa a ser da própria organização.

Visão geral

O Gestão Segura pode usar um Google Drive compartilhado como repositório padrão da organização. Quando a integração é concluída, os anexos enviados pelo sistema passam a ser gravados no Drive definido na configuração do licenciado.

A documentação abaixo segue o mesmo padrão visual das apresentações do produto, mas em formato de tutorial direto, focado em implantação e validação.

Antes de começar

Conta Google Workspace ativa
Permissões Acesso administrativo ao Google Cloud
Recursos Shared Drives e Service Accounts habilitáveis

Contas gratuitas do Google não atendem bem este cenário, porque a integração depende de Shared Drives.

Pré-requisitos

Base da configuração
  • Possuir uma conta do Google Workspace.
  • Ter permissões administrativas no Google Cloud Platform.
  • Ter permissão para criar Shared Drives e Service Accounts.

Passo a passo

Fluxo de implementação
1. Criar um projeto no Google Cloud Google Cloud Console
  1. Acesse console.cloud.google.com.
  2. Clique em Selecionar projeto e depois em Novo Projeto.
  3. Informe nome do projeto e organização, se aplicável.
  4. Finalize em Criar.
2. Habilitar a Google Drive API API
  1. Com o projeto selecionado, acesse a biblioteca de APIs.
  2. Pesquise por Google Drive API.
  3. Abra a API e clique em Ativar.
3. Criar a Service Account Credencial
  1. Acesse a área de Service Accounts do projeto.
  2. Clique em Criar Conta de Serviço.
  3. Informe nome e ID da conta.
  4. Finalize sem adicionar permissões extras nesta etapa.
4. Gerar a chave JSON Autenticação
  1. Abra a Service Account criada.
  2. Acesse a aba Chaves.
  3. Escolha Adicionar chave e depois Criar nova chave.
  4. Selecione o tipo JSON e conclua a criação.

Guarde o arquivo JSON com segurança, pois ele será usado pelo Gestão Segura na autenticação.

5. Criar o Drive compartilhado Repositório
  1. Acesse drive.google.com.
  2. No menu lateral, entre em Drives Compartilhados.
  3. Clique em Novo e defina o nome do Drive.
6. Compartilhar o Drive com a Service Account Permissão

Adicione o e-mail da Service Account como membro do Drive Compartilhado com permissão de Editor.

Sem essa permissão, o Gestão Segura não consegue enviar nem ler arquivos no Google Drive.

7. Configurar o Gestão Segura Aplicação
  1. Acesse as configurações da organização no Gestão Segura.
  2. Entre em Storage e depois em Google Drive.
  3. Envie o JSON da Service Account.
  4. Informe o ID do Drive Compartilhado, se a interface solicitar.
  5. Salve a configuração.
8. Localizar o ID do Drive Compartilhado Identificador

O ID normalmente aparece na URL do Drive. Exemplo: 

https://drive.google.com/drive/folders/0AFxxxxxxxxUk9PVA

O identificador a ser usado é 0AFxxxxxxxxUk9PVA.

9. Validar a configuração Conferência

Após salvar, o sistema deve validar automaticamente:

  • Conexão com a Google Drive API.
  • Acesso ao Drive Compartilhado.
  • Permissão de leitura.
  • Permissão de escrita.

Problemas comuns

Diagnóstico rápido
Erro: permissão negada Acesso

Causa provável: a Service Account não foi adicionada ao Drive Compartilhado.

Solução: revise o compartilhamento e confirme a permissão de Editor.

Erro: API não habilitada Google Cloud

Causa provável: a Google Drive API não foi ativada no projeto.

Solução: ative a API no Google Cloud Console.

Erro: Drive não encontrado Identificação

Causa provável: o ID do Drive está incorreto.

Solução: revise o ID informado na configuração do Gestão Segura.
